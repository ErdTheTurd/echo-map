# Echo Map website

This repository holds the public marketing site for Echo Map, an iOS app that estimates how sound may bounce inside a room you scan (or a built-in demo room). Results are geometry-based simulations, not acoustic measurements.

The site is published at [erdtheturd.github.io/echo-map](https://erdtheturd.github.io/echo-map/).

This repo is the website only. It does not contain the app’s source code.
